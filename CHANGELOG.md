# Changelog

## 1.4.3

- Creates point, polyline, and polygon layers from CSV, XLSX, and supported XLS coordinate tables.
- Supports X, Y, optional Z, point-order fields, and coordinate-system transformation.
- Writes Shapefile or GeoPackage outputs and automatically adds successful results to QGIS.
- Validates coordinate rows, output geometry, and created files before completion.
- Displays live processing progress from 0 to 100 percent.
- Includes sample coordinate data and usage documentation.
